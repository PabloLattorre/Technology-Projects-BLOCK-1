# Part 1 – Hardware vs Software

## Explain Hardware
Write **at least 50 words** explaining what hardware is.

Computer hardware refers to the physical parts you can see and touch in a computer. Those parts work together to process, store information, and performer tasks, for example of hardware include the CPU, RAM, hard drive, motherboard, and input devices such as keyboard, mouse, and also output such as monitor, speaker and projectors.
---

## Explain Software
Write **at least 50 words** explaining what software is.

Software is a set of programs, applications, and instruction that tell a computer what to do. Examples of that are operating system where memory, processes, hardware and files manage the computer and also drivers allow hardware to communicate with the OS. Software is digital and cannot be physically touched, software is essential because it helps to computer work and allows user to complete tasks efficiently.
---

## How Do Hardware and Software Interact?
Write **at least 50 words** describing how they interact.

Hardware and software work together to make a computer function. Hardware is the physical pat of a computer and software is the set of programs and instruction that tell the hardware what to do. Without hardware, software cannot run, and without software, hardware cannot perform most useful tasks. Hardware and software depend on each other.
